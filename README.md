# Audora

Audora is a cross-platform desktop media player for macOS, Windows, and Linux. It plays local audio and video and lets people create named, timestamped notes while media is playing, then return to those moments later.

Audora is planned as a complete, maintainable open-source product, not a throwaway prototype. The project intends to release under the Apache License 2.0. Product and engineering decisions are documented before implementation begins.

## Project status

**Phase 0 (Product and design baseline) is complete; Phase 1 (Technical validation and detailed design) is ready to start.** Read [the documentation index](docs/README.md) for the product specification, workflows, Figma UI/accessibility baseline, architecture, security model, engineering rules, and release roadmap.

## Intended platforms

- macOS (Apple Silicon and Intel, subject to the supported-release policy)
- Windows (64-bit)
- Linux (64-bit; distribution/package support defined in the platform policy)
